# Study Corner

A small two-page website used to practise a local Git workflow.

Open `index.html` in a browser. The About page contains the checklist added on
the `feature` branch.

The history records the initial pages, a homepage update, a feature branch,
an explicit merge, ignore rules, and a temporary change followed by its revert.
The `feature` branch is retained so the branch activity can be inspected.

`git_commands.txt` lists the Git commands with short explanations.
`local_workflow_transcript.txt` contains the recorded output of the local
workflow before the documentation commit.

The ignore rules exclude `*.log` files and the `temp/` folder. The sample log
and temporary note remain local and are not tracked.
